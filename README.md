# Health & Calorie Calculator 🩺🐍

A practical Python Command-Line Interface (CLI) application that helps users monitor their health by calculating their **Body Mass Index (BMI)** and estimating their **Daily Calorie Needs** based on personal metrics and physical activity levels.

## ✨ Features
- **BMI Calculation:** Computes Body Mass Index and categorizes weight status (Underweight, Ideal Weight, Overweight, or Obesity).
- **Daily Calorie Estimation:** Uses the **Mifflin-St Jeor Equation** adjusted for gender and daily exercise routine.
- **Input Validation:** Protects against invalid inputs (such as entering text instead of numbers) using error handling and loops.
- **Modular Structure:** Organized cleanly using Python functions (`BMI`, `calorie_counting`, `adding_motion_effort`, and `main`).

## 🚀 How to Run
1. Make sure you have **Python 3** installed on your computer.
2. Clone this repository or download the Python file:
   ```bash
   git clone https://github.com
   ```
3. Navigate to the project folder and run the script:
   ```bash
   python health_care.py
   ```
